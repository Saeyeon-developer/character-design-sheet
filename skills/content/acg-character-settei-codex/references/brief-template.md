# Character Brief Template

Use this form when the user's description is incomplete. Empty fields are optional. Do not invent a distinctive feature just to fill every line.

```text
Character settei brief

Role / use:
- e.g. animation model sheet, game character reference, OC design

Age cue and presentation:
- child / teen / adult; gender or presentation; anything to avoid assuming

Personality / read:
- e.g. calm but resolute, warm, intimidating, playful

World / genre:
- e.g. contemporary Japanese school, shrine fantasy, sci-fi

Face and hair (identity anchors):
- hair color:
- hair length and silhouette:
- fringe / bangs:
- hairstyle details:
- hair accessories:
- eye color and shape:
- face shape / distinguishing marks:

Body and silhouette:
- height or proportion cue:
- build:
- distinctive silhouette feature:

Outfit construction (keep identical in all views):
- top / collar / sleeves:
- bottom / hem / layers:
- closures / trim / pattern:
- outerwear:
- shoes:
- accessories:

Palette:
- main:
- secondary:
- accent:
- light / dark neutrals:

Required sheet contents:
- front / side / back: yes
- 3/4 view: optional / yes / no
- expressions: 4–6 preferred; list any specific ones
- detail callouts:
- palette swatches: yes / no

References:
- identity reference image(s):
- layout/template reference image(s):
- role of each image:

Constraints:
- must keep:
- omit / avoid:
- short labels needed: yes / no
```

## Internal master-anchor format

After filling the brief, compress it to a few sentences like this before writing the image prompt:

```text
Master Identity Summary:
An adult Japanese woman with a tall, composed silhouette and a softly angular face.
Keep her long black hair with blunt low bangs, amber eyes, and the small red cord at
the left temple. Her fixed outfit is an ivory layered kimono with deep teal trim,
wide sleeves, a rust obi, split-toe socks, and dark wooden sandals; preserve this
construction, shoes, accessory placement, and palette in front, side, back, and all
expressions. Her baseline read is calm, capable, and protective.
```

Keep the summary concrete and short. The summary is working context for generation, not an additional user-facing document unless requested.
